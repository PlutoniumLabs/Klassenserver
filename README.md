# Klassenserver
Hier werden die Datein für zukünftige Klassenserver gehostet werden, anfangend mit dem 8.

Mit [provisioner](https://github.com/lumentae/provisioner) gemanaged

## Beitragen
Um dieser Repository beizutragen zu können, musst du [provisioner](https://github.com/lumentae/provisioner) installiert haben

### Installation von Provisioner
1. Gehe auf die [Releases](https://github.com/lumentae/provisioner/releases/latest) von [provisioner](https://github.com/lumentae/provisioner) und lade entweder `Windows-Release.zip` oder `Linux-Release.zip` herunter
2. Extrahiere die heruntergeladene Datei
3. (optional) Füge den Ordner, wo die `provisioner` Datei drin ist, in deinen Path ein

### Herunterladen von dieser Repository
0. Erstelle ein Fork von dieser Repository
1. Klone die Git Repository mit `git clone https://github.com/<dein Nutzername>/Klassenserver`
2. `cd Klassenserver`
3. Du hast jetzt Zugriff auf die Repository und kannst jetzt die Dateien bearbeiten (Mehr dazu auf der Seite von [provisioner](https://github.com/lumentae/provisioner))
4. Wenn du fertig bist, kannst du deine Änderungen committen (Ich empfehle die VS Code Erweiterung für Git!) und dann über die GitHub Seite von deinem Fork kannst du einen Pull Request machen
